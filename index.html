먼저 GitHub 비공개 저장소의 Repository Secret 등록 화면과 OAuth Actions 실행 화면을 다른 탭에 준비하세요.

아래 현재 주소를 카카오 Redirect URI와 GitHub의 KAKAO_REDIRECT_URI 변수에 동일하게 등록해야 합니다.

인증 코드가 메모리에 준비됐습니다. 아래 버튼으로 복사한 뒤 GitHub의 비공개 저장소에 KAKAO_AUTH_CODE Secret으로 저장하고, 즉시 Initialize Kakao OAuth를 실행하세요.

코드가 만료되거나 이미 사용됐다면 새로 로그인해야 합니다. 이 페이지에는 액세스·리프레시 토큰이 전달되지 않습니다.
